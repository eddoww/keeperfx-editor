# Security

The editor reads files from your KeeperFX install and from downloaded Workshop archives, and
can talk to a running game over a local TCP connection. Problems in any of these, such as an
archive that writes outside the folder it is installed into, are security issues.

## Supported versions

Only the latest release receives fixes.

## Reporting a problem

Please report security problems privately, using "Report a vulnerability" on the repository's
Security tab on GitHub, rather than in a public issue. Include the editor version, your
operating system and the steps or file needed to reproduce the problem.
